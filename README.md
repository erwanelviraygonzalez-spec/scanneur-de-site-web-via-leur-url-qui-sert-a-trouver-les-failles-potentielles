# scanneur-de-site-web-via-leur-url-qui-sert-a-trouver-les-failles-potentielles
Scanner de vulnérabilités web analysant une URL pour détecter les failles potentielles : XSS, SQLi, IDOR, CSRF, redirections ouvertes, fichiers sensibles exposés et mauvaises configurations. Génère un rapport JSON des risques identifiés. Utilisation uniquement avec autorisation.
